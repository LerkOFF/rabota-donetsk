# Модель данных

## Вакансия

| Поле | Значения |
| --- | --- |
| profession | нормализованное название: бариста, бухгалтер, грузчик |
| title_raw | заголовок как в источнике |
| category | общепит, торговля, офис, склад, производство, стройка, транспорт, медицина, образование, услуги, другое |
| work_format | офис, точка или зал, объект, склад, выезд, удалённо, вахта |
| employment | постоянно, подработка, на сегодня, сменная |
| schedule | 5/2, 2/2, 3/3, сутки, свободный, часы словами |
| pay_min, pay_max | число в рублях |
| pay_period | месяц, смена, день, час, задача |
| pay_daily | выплата каждый день или раз в два дня |
| pay_monthly_estimate | оценка в месяц, помечена как расчёт |
| city | Донецк, Макеевка, Горловка, Мариуполь, Енакиево и другие |
| district | район города, микрорайон, улица, если указано |
| experience | не нужен, от года, от трёх лет |
| age_min | 18, 21 и так далее |
| requirements | образование, права, 1С, медицинская книжка |
| employer | название, если есть |
| contacts | телефон, ник Telegram, MAX, email |
| source | канал или паблик, ссылка на оригинал, время публикации |
| duplicate_of | ссылка на главную вакансию, если это дубль |
| status | активна, закрыта, скрыта по жалобе |

## Справочники

- Профессии: около 300 нормализованных названий с синонимами ("продавец-кассир", "кассир торгового зала" дают "кассир").
- Города и районы ДНР с вариантами написания.
- Стоп-слова: реклама каналов, "разместить вакансию", признаки услуг и набора на службу.
- Таблица букв-двойников для приведения к кириллице.

## Жалобы и удаление

Таблица обращений: вакансия, причина, статус, время. По запросу работодателя вакансия скрывается, источник остаётся в чёрном списке сборщика.
