# Риски

| Риск | Что делаем |
| --- | --- |
| Авторские права и правила площадок | показываем извлечённые факты и ссылку на оригинал, текст поста и картинки целиком не копируем |
| Персональные данные | контакты работодателей уже опубликованы ими; резюме и личные объявления не собираем; кнопка "удалить по запросу" |
| Мнимые вакансии: закладки, предоплата, "ставки", подозрительно высокая оплата без условий | стоп-лист слов, пометка подозрительных, ручной просмотр, жалоба на карточке |
| Закрытый доступ VK, hh.ru, Avito | ключ VK для сайта, регистрация приложения hh.ru, Avito позже или не берём |
| Блокировка сборщиков | вежливая частота запросов, кэш, нормальный User-Agent, отказ от источника при запрете |
| Ошибки разбора | размеченный набор, показ оригинала рядом с карточкой, жалоба на неверные данные |
| Зависимость от одного провайдера модели | провайдер задаётся настройкой |
| Набор на военную службу в потоке вакансий | отдельная категория, решение показывать ли её, принимает владелец |
