# Стек и архитектура

## Схема

```
источники -> сборщики -> сырые посты -> очистка -> разбор текста
                                              \-> разбор картинок
         -> нормализация -> склейка дублей -> вакансии -> сайт
```

## Технологии

| Слой | Выбор | Почему |
| --- | --- | --- |
| Язык сборщиков и разбора | Python 3.12 | богатые библиотеки для разбора текста, простые сборщики |
| HTTP и разбор HTML | httpx, selectolax | быстро, без браузера |
| База | PostgreSQL 16, расширение pg_trgm, полнотекстовый поиск | дубли и поиск с опечатками без отдельного движка |
| Очередь и расписание | cron или systemd timers, позже очередь на Redis | нагрузка небольшая |
| Разбор текста | словарь профессий, регулярные выражения для оплаты, графика, телефона; языковая модель для неясных случаев, ответ строгим JSON | дёшево: большинство постов типовые |
| Разбор картинок | языковая модель с поддержкой изображений, тот же JSON-формат, что у текста | отдельный OCR не нужен, модель понимает, что на афише вакансия |
| Сайт | серверный рендер на Python (FastAPI и шаблоны Jinja2) | индексация поисковиками, одна кодовая база с разбором |
| Стили | чистый CSS, без тяжёлого фреймворка | скорость на слабых телефонах |
| Хостинг | один VPS, nginx, TLS | нагрузка маленькая |
| Карта | OpenStreetMap, районы Донецка | без платных ключей |
| Мониторинг | логи и проверка свежести по источникам | видно, какой сборщик упал |

Провайдер языковой модели задаётся в `.env`, код не привязан к одному поставщику.

## Структура репозитория (план)

```
collectors/   сборщики по источникам
pipeline/     очистка, разбор, нормализация, склейка
vision/       классификация и распознавание картинок
web/          сайт
db/           схема и миграции
docs/         документация
tests/        тесты разбора на размеченных примерах
```

## Ключи и настройки

Все ключи (VK, hh.ru, модель, база) задаются в `.env` на сервере. В репозитории только `.env.example` с заглушками.

## Тесты

Основа качества разбора: набор из 300 размеченных вручную постов и афиш, по нему считаем точность на каждое изменение правил. Тесты сборщиков идут на сохранённых образцах ответов, без обращения к сети.
