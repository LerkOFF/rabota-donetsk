# Работа Донецк

Сайт-агрегатор вакансий Донецка и ДНР: работа-донецк.рф

Вакансии лежат в десятках Telegram-каналов, пабликов VK, каналов MAX и на сайтах. Посты длинные, с эмодзи, рекламой и повторами, зарплата записана по-разному, часть вакансий опубликована картинкой. Проект собирает всё в одно место и показывает коротко: "Бариста, Донецк, Ворошиловский район, 4000 ₽ за смену, 2/2, в заведении".

## Что делает сайт

- Собирает вакансии из Telegram, VK, MAX, Работы России, hh.ru.
- Читает текст и картинки, достаёт профессию, оплату, график, район, контакт.
- Склеивает дубли, убирает рекламу и посты не про работу.
- Показывает чистую карточку с фильтрами: город и район, категория, формат работы (в офисе, на объекте, удалённо), оплата за месяц или за смену, без опыта, подработка, ежедневная выплата.
- Всегда ведёт на оригинал вакансии.

## Статус

Работает локально: сборщики Telegram, VK, MAX, Работа России, Мой ЦЗН и hh.ru, разбор текста и картинок, склейка дублей, сайт с фильтрами. Авито закрывает автоматический доступ (капча), сборщик написан, но живых данных пока не получает. Дальнейший порядок работ в [docs/PLAN.md](docs/PLAN.md).

## Запуск локально

```bash
uv sync --group dev                         # окружение
cp .env.example .env                        # добавить ключ VK_ACCESS_TOKEN
.venv/bin/python -m rabota run --limit 10   # собрать по 10 постов с канала, разобрать, склеить дубли
.venv/bin/python -m rabota serve            # сайт на http://127.0.0.1:8000
.venv/bin/pytest                            # тесты, включая браузерные
.venv/bin/ruff check rabota tests scripts   # линтер
```

Локально база SQLite (`data/rabota.db`), схема переносится на PostgreSQL. Команды: `collect`, `process`, `run`, `stats`, `serve`. Демо-база с выдуманными вакансиями: `scripts/seed_demo.py`.

## Настройка

Все ключи и пароли задаются в `.env` на сервере, образец в `.env.example`. В репозиторий секреты не попадают.
